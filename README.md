CONTRIBUTING, SECURITY) s'appliquent par défaut aux repos qui n'ont pas les leurs.
`profile/README.md` s'affiche sur la page de l'organisation.

⚠️ Ce repo doit être **public** pour que les defaults fonctionnent : n'y mettez rien de sensible.
